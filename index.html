Get the extension

Every good link, sorted.

Brain Vault is a Chrome extension for saving articles, posts and app inspiration with a note on why. Jev files each one → and your library publishes to your own site.

Saving an article in one click, note included
Save from anywhere

Keep it the moment you find it.

Click the icon, press ⌘⇧S, or right-click any page or link. Add a line about why it caught your eye, and it’s saved.

Right-click

Deep in a great article? Right-click, choose Save to Brain Vault, and the panel opens beside the page you’re reading.

Screenshots

Saving inspiration? Pick the Inspiration shelf and drag out the exact part of the page you want to remember. It’s kept with your note.

Can’t I just use bookmarks?

It files itself.

Jev reads the page and your note, then picks a shelf, a topic and tags in one quick request. Your own choice always wins.

ReadingEssays, articles and long posts on X.

Where it lands

Your library, on your own site.

Everything goes into one file in your GitHub repo and publishes with GitHub Pages. Search it later by title, tag, or the note you wrote.

Find it again

⌘K searches your notes too, so “that writing thing” finds it.

Publish

Flip “Publish to GitHub” and each save goes live on your site.

Free and open source

Make your own Brain Vault.

A Chrome extension plus a small local helper. Your vault lives in your own GitHub repo, and nothing is stored anywhere else.

Download the extension View on GitHub ›
1

Get the code

Clone the repo, or use it as a template so your vault lives in your own GitHub account.

$ git clone
2

Add it to Chrome

Open chrome://extensions, turn on Developer mode, and load the extension folder.

chrome://extensions → Load unpacked
3

Start saving

Add your TypeSafe key for Jev, then run the helper. Your first save can go live the same minute.

$ python3 bridge/server.py
